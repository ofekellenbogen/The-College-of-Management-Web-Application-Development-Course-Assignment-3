משחק ללימוד HTTP ו-REST API (מטלה 3)

אפליקציית Web אינטראקטיבית לתרגול תקשורת Client-Server, מתודות HTTP, ועקרונות RESTful API.

⚠️ שים לב: אפליקציה זו מבוססת על צד שרת אמיתי (Node.js & Express) שאינו יכול לרוץ ב-GitHub Pages.
על פי הנחיות המטלה, יש להריץ את השרת בסביבה מקומית בהתאם להוראות שלהלן.

🚀 הוראות התקנה והרצה מקומית

1. שכפול המאגר / פתיחת התיקייה בטרמינל:

git clone https://github.com/ofekellenbogen/The-College-of-Management-Web-Application-Development-Course-Assignment-3.git cd The-College-of-Management-Web-Application-Development-Course-Assignment-3

2. התקנת תלויות השרת:

npm install

3. הפעלת שרת ה-Express:

npm start

4. פתיחת האפליקציה בדפדפן:

  • 🎮 עמוד המשחק הראשי: http://localhost:3000
  • 📋 עמוד סכמות המערכת (SSR): http://localhost:3000/schemas

🎮 שלבי המשחק (10 שלבים מגוונים)

שלב 1: שליפת כל המוצרים (GET /api/products) - היכרות עם שליפת משאבים.
שלב 2: שליפת מוצר בודד לפי מזהה (GET /api/products/1) - שימוש ב-Route Parameter.
שלב 3: בקשה למשאב שאינו קיים (GET /api/products/999) - טיפול בשגיאת 404 Not Found.
שלב 4: סינון מוצרים לפי קטגוריה (GET /api/products?category=Electronics) - שימוש ב-Query Parameter.
שלב 5: שילוב מספר Query Parameters (GET /api/products?category=Books&sortBy=price&order=asc) - סינון ומיון לפי מחיר.
שלב 6: יצירת מוצר חדש (POST /api/products) - העברת Request Body בפורמט JSON וקבלת 201 Created.
שלב 7: עדכון פרטי מוצר קיים (PATCH /api/products/4) - שילוב Route Param ו-Request Body.
שלב 8: מחיקת מוצר מזיכרון השרת (DELETE /api/products/7) - שימוש ב-DELETE.
שלב 9: שליפת משאבים מקושרים (GET /api/products/1/reviews) - קשר 1 לרבים (Nested Resources).
שלב 10: הוספת ביקורת למשאב מקושר (POST /api/products/2/reviews) - יצירת משאב היררכי.

🛠️ מאפיינים טכנולוגיים

  • Node.js & Express: שרת RESTful מלא המנהל מוצרים וביקורות בזיכרון השרת עם אפשרות איפוס.
  • Server-Side Rendering (EJS): עמוד משחק ועמוד סכמות מלאים המרונדרים בצד השרת.
  • בדיקת נכונות בשרת בלבד: בדיקת התשובות והלוגיקה מתבצעות אך ורק בשרת ללא חשיפת הפתרונות לקליינט.
  • Vanilla JavaScript & AJAX: שליחת בקשות HTTP אמיתיות לשרת ועדכון הממשק בזמן אמת ללא ריענון עמוד.
