## 📌 אודות הפרויקט
משחק אינטראקטיבי עשיר ומודרני הממחיש בצורה מעשית וחווייתית את אופן התקשורת בין **צד הלקוח (Client)** ל**צד השרת (Server)** באמצעות פרוטוקול **HTTP** ועקרונות **REST API**.

במהלך המשחק, השחקן נחשף ל-10 תרחישים אמיתיים מעולם פיתוח ה-Web המבוססים על שני משאבים מקושרים (**מוצרים - Products** ו**ביקורות - Reviews**). השחקן מרכיב בעצמו בקשות HTTP אמיתיות (Method, Path, Route Parameters, Query Parameters, Request Body), שולח אותן באמצעות **AJAX**, ומקבל תגובה חיה ומשוב מפורט משרת ה-Node.js & Express.

> [!WARNING]
> **שימו לב - סביבת הרצה מקומית (ללא GitHub Pages):**  
> בהתאם להנחיות המטלה, פרויקט זה כולל שרת Node.js & Express פעיל המנהל נתונים בזיכרון ומבצע SSR באמצעות EJS. לפיכך, **אין להריץ את הפרויקט ב-GitHub Pages**, אלא בסביבה מקומית לפי ההוראות המפורטות להלן.

## 🕹️ מהלך המשחק — 10 שלבי לימוד מגוונים (מעבר למינימום של 8)

המשחק כולל **10 שלבים עשירים** המתרגלים מגוון רחב של מושגים ותרחישים בעולם ה-REST:

| שלב | נושא המשימה | מתודת HTTP | נתיב הבקשה (Endpoint) | מושגים מתורגלים |
| :---: | :--- | :---: | :--- | :--- |
| **1** | **שליפת כל המוצרים** | `GET` | `/api/products` | שליפת משאב ברבים, REST Naming |
| **2** | **שליפת מוצר בודד לפי מזהה** | `GET` | `/api/products/1` | Route Parameters, שליפת משאב יחיד |
| **3** | **טיפול בשגיאת משאב לא קיים** | `GET` | `/api/products/999` | HTTP 404 Not Found, Error Handling מכוון |
| **4** | **סינון מוצרים לפי קטגוריה** | `GET` | `/api/products?category=Electronics` | Query Parameters, סינון נתונים אמיתי |
| **5** | **שילוב סינון ומיון מרובה** | `GET` | `/api/products?category=Books&sortBy=price&order=asc` | Multiple Query Parameters, מיון וסינון משולב |
| **6** | **הוספת מוצר חדש** | `POST` | `/api/products` | Request Body (JSON), HTTP 201 Created |
| **7** | **עדכון מחיר של מוצר קיים** | `PATCH` / `PUT` | `/api/products/4` | Route Param + Request Body, עדכון חלקי/מלא |
| **8** | **מחיקת מוצר מהמערכת** | `DELETE` | `/api/products/7` | Route Param, מחיקת משאב ב-REST ומחיקה מדורגת |
| **9** | **שליפת ביקורות של מוצר** | `GET` | `/api/products/1/reviews` | Nested Resources, קשר 1 לרבים (1:N) |
| **10** | **הוספת ביקורת למוצר מקושר** | `POST` | `/api/products/2/reviews` | יצירת משאב היררכי, Body + Route Param |

## 🌟 סעיפי רשות ובונוסים שמומשו במלואם (לציון 100)

1. **10 שלבים מתקדמים במקום מינימום 8:**
   - שילוב של יותר ממושג אחד בלפחות 4 שלבים שונים (שלבים 5, 7, 9, 10).
   - תרגול כל 5 מתודות ה-HTTP: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`.
   - שלב שגיאה מכוונת מהשרת (`404 Not Found`) בשלב 3.
   - שלב ניצול קשר בין שני משאבים שונים (מוצרים וביקורות) בשלבים 9 ו-10.

2. **בדיקת נכונות בצד השרת בלבד + העברת מזהה שלב בכל בקשה:**
   - בכל בקשת HTTP שנשלחת במשחק מועברת כותרת `X-Stage-Id` (או פרמטר שאילתה).
   - Middleware בשרת בודק את הבקשה ומחזיר ישירות בכותרות התגובה (`X-Stage-Valid`, `X-Stage-Feedback`) את תוצאת האימות.
   - **אפס פתרונות בקוד הלקוח:** טופס הבקשה נטען ריק ונקי, והמשתמש מרכיב בעצמו את המתודה, הנתיב, הפרמטרים וה-Body.

3. **מערכת ניקוד, ניסיונות ושמירת התקדמות ב-`localStorage`:**
   - מעקב אחר ניקוד (+100 לכל שלב), ספירת ניסיונות, ופס התקדמות דינמי באחוזים.
   - התקדמות המשחק נשמרת אוטומטית בדפדפן (`localStorage`) ולא נאבדת ברענון הדף!
   - כפתור ייעודי בראש העמוד: **"⭐ איפוס התקדמות"** המאפשר להתחיל מחדש בכל עת.

4. **אפשרות חזרה לשלבים קודמים:**
   - Stepper אינטראקטיבי המאפשר קפיצה חופשית לכל שלב בכל עת, עם סימון `✓` ירוק לשלבים שהושלמו.

5. **תמונת מצב חיה בזיכרון השרת (Live Server State):**
   - לוח טבלאות בזמן אמת המציג את המוצרים והביקורות בזיכרון השרת, וממחיש כיצד בקשות `POST`, `PATCH`, ו-`DELETE` משנות בפועל את הנתונים בזמן ריצה.
   - כפתור **"🔄 איפוס נתונים"** להחזרת נתוני השרת למצב ברירת המחדל מתוך קובץ ה-JSON.

6. **עיצוב פרימיום ורספונסיביות מלאה (Mobile & Desktop):**
   - עיצוב Dark Cyber מודרני, Glassmorphism, טיפוגרפיה איכותית (Assistant & Fira Code).
   - רספונסיביות מלאה למכשירים ניידים (<640px) ולמסכים רחבים.
   - בונה שאילתות דינמי (Dynamic Query Params Builder) עם הוספה והסרה קלה.
   - עורך JSON Body עם אימות תחביר מובנה וכפתור "⚡ Format JSON".
   - הצגת תגובת שרת עשירה: תגיות סטטוס מוארות (2xx, 4xx, 5xx), מדידת זמן תגובה במילישניות, וכפתור העתקת JSON.

7. **עמוד סכמות נתונים ב-SSR (`/schemas`):**
   - עמוד EJS מלא המציג את כל שדות המשאבים, סוגי הנתונים (Data Types), שדות חובה, דוגמאות JSON, ומפת נתיבי REST מלאה.
